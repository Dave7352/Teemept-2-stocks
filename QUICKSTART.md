# Quick Start Guide

Get started with the Stock Record Keeping application in 3 easy steps!

## Step 1: Installation

```bash
# Clone the repository
git clone https://github.com/Dave7352/Teemept-2-stocks.git
cd Teemept-2-stocks

# Install dependencies
pip install -r requirements.txt
```

## Step 2: (Optional) Load Demo Data

```bash
# Create sample stocks to explore features
python demo_data.py
```

This creates 10 sample stocks with different statuses to demonstrate the application.

## Step 3: Launch Application

```bash
python stock_app.py
```

## First Steps in the Application

1. **Add Your First Stock**
   - Click "Add Stock"
   - Enter stock details (name, ticker, price, shares)
   - Click "Fetch Info" to auto-populate current data
   - Select a position status
   - Click "Save"

2. **Update Prices**
   - Click "Refresh Prices" to fetch current market prices

3. **Explore Features**
   - Double-click stocks to see details
   - Try different sort options
   - Click "Check Alerts" to see review reminders

## Key Features

✅ Track unlimited stocks  
✅ Real-time price updates (Yahoo Finance)  
✅ Color-coded position statuses  
✅ Review reminders and earnings alerts  
✅ Attach notes and images  
✅ Sort by value, performance, status  
✅ 100% free and open source  
✅ Works offline (except price updates)
